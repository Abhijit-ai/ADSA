# ADSA Presentation – Splay Trees

This folder contains the presentation for the **Advanced Data Structures and Algorithms (ADSA)** course on the topic **Splay Trees**.

The presentation explains the structure, operations, and analysis of **Splay Trees**, a self-adjusting binary search tree.

---

## 📚 Description

Splay Trees are **self-adjusting binary search trees** that move recently accessed elements closer to the root using tree rotations.  
This property allows frequently accessed elements to be retrieved faster over time.

The presentation demonstrates:
- How splaying works using rotations  
- Why zig-zig is better than double zig  
- How amortized analysis guarantees good performance
